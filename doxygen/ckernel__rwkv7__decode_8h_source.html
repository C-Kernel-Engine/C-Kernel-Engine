10/*
11 * RWKV-7 single-token (T=1, B=1) FP32 decode reference.
12 *
13 * Token shift: xm = x + mu*(shift-x) with shift_out = x.
14 *
15 * WKV generalised delta rule, multiplicative decay, per head with state
16 * [N,N] in (value,key) axes:
17 * decay[j] = exp(w_log[j])
18 * b[j] = kk[j]*a[j]
19 * S_new[i,j] = S[i,j]*decay[j] - (S[i,:].kk)*b[j] + v[i]*k[j]
20 * y[i] = sum_l S_new[i,l]*r[l]
21 * GroupNorm eps is norm_eps*head_dim. Bonus is per head:
22 * s_h = sum(r_h*k_h*rk_h), y_h += s_h*v_h, with rk [H,N].
23 * Output is y_out = (groupnorm(y)+bonus)*g elementwise; the final CxC
24 * output projection stays with the caller's GEMV.
25 * v-mixing towards v_first and the LoRA chains are separate units below;
26 * the WKV takes final w_log/k/v/kk/a/g (kk L2-normalised, k scaled by
27 * 1+(a-1)*k_a).
28 *
29 * Layouts (all FP32, row-major, flat C = H*N):
30 * - vectors: [C]; rk: [H,N] (row per head)
31 * - state: [H,N,N], head h at offset h*N*N, row i at +i*N+j
32 * - LoRA down factors [C,R], up factors [R,C]; biases [C] (g has none)
33 * - channelmix Wk [K,C] (expand), Wv [C,K] (project)
34 *
35 * Limits (violations are hard errors): head_dim <= 512, num_heads <= 256,
36 * LoRA ranks <= 512, hidden_dim <= 8192, norm_eps > 0.
37 *
38 * All functions return 0 on success, -1 on bad args, except
39 * ck_rwkv7_channelmix_scratch_elems, which returns the required scratch
40 * element count (0 on bad args). No malloc/free.
41 * Unless an alias is explicitly documented, outputs must be disjoint from
42 * inputs and each other; callers own storage sizes. State-step/state-decode
43 * permit state_out == state_in, and norm_kk permits kk_out == kk_in.
44 */
