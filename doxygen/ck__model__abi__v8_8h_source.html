73/* Optional when CK_MODEL_CAP_SEQUENCE_STATE_SWITCH is set. All calls, including
74 * decode and reset, remain serialized. Nonzero handles are generation-tagged
75 * IDs; retired handles and handles from an earlier model load are rejected.
76 * The default state uses the model arena. Each extra sequence needs a caller-
77 * owned aligned KV arena of the reported size; it must remain alive through

88/* Optional when CK_MODEL_CAP_BATCH_DECODE_TWO_ROWS is set. The first version
