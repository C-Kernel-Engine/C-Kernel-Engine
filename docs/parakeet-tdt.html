Parakeet TDT 0.6B native CPU bring-up

Short WAV E2E passes

CKE converts the pinned nvidia/parakeet-tdt-0.6b-v3 checkpoint to BUMPWGT5, decodes PCM WAV audio, runs the 24-layer FastConformer encoder and the TDT prediction/joint networks, and emits text without importing PyTorch or Transformers during inference.

Reproduce the validated path

hf download nvidia/parakeet-tdt-0.6b-v3 \
  --revision 541d1f99c6b0c3cd0b11a95167540bb8edefd82b \
  --local-dir .ck_models/parakeet-tdt-0.6b-v3

python version/v8/scripts/convert_safetensors_to_bump_v8.py \
  --checkpoint .ck_models/parakeet-tdt-0.6b-v3 \
  --output .ck_build/parakeet-tdt-0.6b-v3/weights.bump \
  --config-out .ck_build/parakeet-tdt-0.6b-v3/config.json \
  --manifest-out .ck_build/parakeet-tdt-0.6b-v3/weights_manifest.json \
  --arch parakeet_tdt --dtype fp32

python version/v8/scripts/run_parakeet_native_v8.py \
  --model .ck_build/parakeet-tdt-0.6b-v3 \
  --audio version/v8/test_assets/parakeet_tdt_0_6b_v3/2086-149220-0033.wav \
  --fixture docs/notes/artifacts/parakeet_tdt_0_6b_v3_2086-149220-0033_fp32.npz \
  --engine build/libckernel_engine.so \
  --audio-lib build/libckernel_audio.so \
  --decode --output .ck_build/parakeet-tdt-0.6b-v3/native-e2e.json

Certification boundary

The exact reference result covers one 7.435-second English, mono, 16 kHz PCM WAV. Deterministic full-attention and overlapping-window runs pass on a complete five-minute English recording, and a synthetic 48 kHz stereo resampling case also passes. Multilingual speech, real-world resampling quality, 42-minute audio, concurrent sessions, generated-circuit execution, and diarization remain open. The current runtime orchestration is a thin Python layer over native CKE kernels and BUMP weights.
